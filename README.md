# plakar integrations

Integrations for [plakar](https://plakar.io), one Go module per
directory. Each lives on its own `integration/<name>` branch, where the
pull requests go; `main` receives the merges and the release tags.

- [minecraft](minecraft/): back up and restore a Minecraft server
- [immich](immich/): back up and restore an Immich user over its API, or a whole server as a database dump plus files
